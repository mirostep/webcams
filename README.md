# 🌍 Webcams – světové webkamery

Veřejný seznam internetových webkamer z různých koutů světa ve formátu M3U.

### 📺 Playlist
[**Stáhnout playlist webcams.m3u**](webcams.m3u)

### ▶️ Použití
Playlist lze otevřít v přehrávačích:
- VLC Media Player
- Kodi
- dalších přehrávačích podporujících M3U

### 🔄 Aktualizace
Seznam webkamer je průběžně aktualizován. Funkčnost streamů se může měnit v závislosti na jejich provozovatelích.

### ⚠️ Upozornění
Playlist obsahuje odkazy na veřejně dostupné streamy třetích stran. Projekt není jejich provozovatelem.
